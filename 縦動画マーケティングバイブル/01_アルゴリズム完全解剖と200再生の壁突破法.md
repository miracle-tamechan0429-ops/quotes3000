# 01｜アルゴリズム完全解剖と「200再生の壁」突破法

SNS・YouTubeで縦型ショート動画（TikTok / Instagramリール / YouTubeショート）の攻略を発信しているトップマーケター・運用代行各社が共通して解説している**「最新アルゴリズムの内部構造」**と、**「フォトモード（カルーセル投稿）特有のバズらせる方程式」**をまとめます。

---

## 1. TikTokアルゴリズムの「階段式テスト配信」構造

TikTokはフォロワー0人の初期アカウントであっても、すべての投稿に対して必ず**初期テスト配信（約150〜300人）**を行います。

```
【第1段階】200〜300再生（初期テスト枠）
   ↓ スワイプ突破率・完走率・保存率が基準クリア
【第2段階】1,000〜3,000再生（中規模テスト枠）
   ↓ コメント率・シェア率・保存率が基準クリア
【第3段階】10,000〜50,000再生（プチバズ枠）
   ↓ 大衆層でも維持率が落ちない
【第4段階】100,000〜1,000,000再生以上（大バズ枠）
```

### 🚨 なぜ「100〜300再生」でピタッと止まるのか？
第1段階の200人に配信された際、AIは以下の**4つのシグナル（重要度順）**を採点しています。

| 優先順位 | 評価指標（シグナル） | フォトモード（5枚画像）での意味 | 200再生突破の目安ライン |
| :--- | :--- | :--- | :--- |
| **第1位** | **初回スワイプ突破率（2秒維持率）** | 1枚目を見てそのまま下へスクロールせず、**2枚目へ横スワイプした人の割合** | **60%〜70%以上** |
| **第2位** | **完走率・総滞在時間** | **5枚目（最後）までスワイプして読んだ人の割合**＋1投稿あたりの滞在秒数（12〜20秒以上） | **完走率 35%〜45%以上** |
| **第3位** | **保存率（ブックマーク）・シェア率** | 見た人のうち**「保存」または「シェア」を押した割合**（いいねの約5〜10倍の加点） | **保存率 2%〜5%以上** |
| **第4位** | **コメント率（議論の深さ）** | コメント数およびコメント欄を開いて読んでいる時間（滞在時間に直結） | **コメント率 0.5%〜1%以上** |
| 第5位 | いいね率 | 単なる「いいね」（現在は最も重みが低い） | 5%〜10% |

> **プロの結論**：「いいね」が10個ついても、**「1枚目で7割がスワイプ離脱している」**または**「保存が0件」**だと、AIは200〜300再生で配信を完全停止します。

## 2. 動画モード vs フォトモード（画像カルーセル）の攻略の違い

多くの人が「動画の感覚」で画像スライドを作って失敗します。フォトモードには固有のアルゴリズムハックが存在します。

### ① 「自動スライド」ではなく「自分の指でめくらせる」のが最大の武器
- ユーザーが自分の指で2枚目・3枚目へスワイプする行為そのものが、TikTokのAIに対して**「強い興味関心シグナル（Active Engagement）」**としてカウントされます。
- したがって、1枚目で結論を全部言ってはいけません。1枚目は**「えっ、なんで？」「それ私のことだ、どうすればいいの？」と思わせて2枚目へ指を動かさせるためだけの装置**です。

### ② 「1枚あたりの文字数」と「滞在時間」の黄金バランス
- 文字が少なすぎる（1枚10文字など）と、全5枚を3秒でめくられてしまい**「総滞在時間が短すぎて評価されない」**現象が起きます。
- 逆に文字が多すぎる（小説のように詰まっている）と、**「読むのが面倒くさい（認知負荷が高い）」**と1枚目・2枚目で離脱されます。
- **黄金比**：
  - **1枚目（表紙）**：**2秒で読める（18〜28文字）** 強烈なフック＋右スワイプ誘導（`➔`）
  - **2枚目・3枚目（展開）**：**3〜4秒で読める（35〜55文字）** 具体的な数字や逆説ストーリー
  - **4枚目（核心の名言）**：視線が中央に釘付けになる**黄金の名言＋その裏の意味**
  - **5枚目（保存＆議論）**：**「あとで見返すための3つの教訓（保存用）」＋「究極の2択（コメント用）」**（ここで5〜8秒滞在させる！）

## 3. 初期アカウントが守るべき運用アルゴリズムの鉄則

1. **BGM（音源）は必ずTikTok内の「トレンド音源（またはエモい定番曲）」を紐付ける**
   - APIで下書き（`MEDIA_UPLOAD`）に届いた後、そのまま無音やデフォルト音で出すのではなく、**名言・感動・夜系アカウントで今伸びているピアノ／アンビエント音源**（例：久石譲系、ノスタルジックなピアノループ、洋楽スローバラード等の人気音源）を選ぶだけで、音源経由のレコメンド枠に乗ります。
2. **投稿公開のゴールデンタイム**
   - サーバーから下書きが届くのは朝9時でOKですが、実際にTikTok上で「投稿」ボタンを押す時間帯、または読まれる時間帯として最も保存率・コメント率が高まるのは：
     - **朝の通勤・通学帯（7:30〜9:30）**
     - **夜の孤独・内省ゴールデンタイム（20:00〜24:30）**（※名言・人間関係・恋愛ジャンルは夜21時〜24時が最も「保存」と「長文コメント」がつきやすい）
3. **コメント欄を開かせている間も「滞在時間」がカウントされ続ける**
   - これがプロの最大の裏技です。ユーザーが1コメ目のアンケートを読んで「みんなどっち選んでるんだろう？」と**コメント欄を開いている秒数もすべて投稿の滞在時間に加算**されます。
   - だからこそ、スライドの最後と1コメ目の連動が極めて重要になります。
